# BasePeak

Teoria della spettrometria di massa: capitoli, figure interattive e Pratica (giochi ed esercizi).
Pagine statiche, nessuna compilazione, si apre anche da file (doppio clic su `mzlab/web/teoria/index.html`).
Accessibile: font Atkinson Hyperlegible e OpenDyslexic, spaziatura WCAG, sfondi crema/azzurro/alto contrasto.

**Stato:** importazione iniziale da mzLab (layout originale dei percorsi). La riorganizzazione, lo stile a menu laterale e la pubblicazione su GitHub Pages sono affidati al coordinatore di questo repository.
