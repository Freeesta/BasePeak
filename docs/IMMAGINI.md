# Immagini del sito

Elenco di tutti i file immagine sotto `assets/`: una riga per file (o per gruppo, solo per le icone del progetto). Il test `tests/test_immagini.py` controlla che ogni immagine sia elencata, che ogni riga corrisponda a un file e che licenza, dimensioni e uso nelle pagine rispettino le regole.

Licenze ammesse nella parte Storia (`assets/img/storia/`): `Pubblico dominio`, `CC0 1.0`, `CC BY 2.0`/`2.5`/`3.0`/`4.0`, `Originale (CC BY 4.0, BasePeak)`. Non sono ammesse licenze NC, ND, BY-SA, immagini «fair use», figure di editori o immagini storiche generate da un'IA. Fuori dalla Storia compare anche `MIT (BasePeak)`, solo per le icone del progetto.

Ogni riga ha questi campi:

- **File**: percorso sotto `assets/`;
- **Mostra**: che cosa si vede;
- **Fonte**: pagina esatta della fonte, oppure `disegno originale`;
- **Autore** e **Data**: come indicati nella pagina della fonte;
- **Licenza**: una di quelle ammesse;
- **Attribuzione**: il testo stampato nella didascalia;
- **Modifiche**: ritaglio, ridimensionamento, conversione;
- **Stato**: `verificata` più la data in cui è stata riletta la licenza.
