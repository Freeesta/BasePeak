## Il problema

Un estratto sintetico di acqua superficiale con tre composti da trovare.

```html
<div class="sim" id="sim-chemi-esempio" data-sim="../assets/sim-chemi-esempio.js" data-preset="esempio"><h3>Figura 32.1 Il percorso completo, un passo alla volta</h3>
<p class="note nota">Percorre in sei passi un esempio sintetico, dal file al livello di confidenza. Dati sintetici, a scopo didattico.</p></div>
```

## 1. Dal file agli spettri centroidati

Si apre il file e si riducono i profili a centroidi.

## 2. Dalle tracce ai picchi

Si costruiscono le tracce di massa e si cercano i picchi.

## 3. Dai picchi alla tabella delle feature

I picchi di più campioni diventano una tabella unica.

## 4. Dallo spettro MS2 al candidato

Gli spettri MS2 si confrontano con una libreria sintetica.

## 5. Il livello di confidenza

Per ogni composto si assegna un livello in base alle prove.

## Che cosa scrivere nel rapporto

Le informazioni da riportare per rendere il risultato verificabile.

## Verifica

Qualche domanda per controllare di avere capito i punti principali.
